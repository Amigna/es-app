# Verb backlog

Verbs still to add, so a new batch doesn't need to scan `src/data/verbs.json` for duplicates. Every verb here was checked against `verbs.json` when this list was made (314 verbs). Work from the top, one batch at a time.

The order is a rough guess at frequency, from memory and not checked against a source: common general verbs first, then everyday ones (house, health, school, travel, feelings), then reflexives, then more formal verbs, with slang and strongly regional verbs last. There are 730 here, a little over the roughly 690 left for the 1,000-verb goal, so weak ones near the end can be dropped. Glosses are starting points for the `en` field.

When adding a batch:

- Follow "How content gets added" in `plan.md`: append to the end of `verbs.json`, then add sentences in the matching sentence file.
- Check how similar verbs are entered in `verbs.json` (`boot`, `accent` for `-iar` and `-uar` verbs like `enviar`, `like` for compounds) and that the engine conjugates each one correctly. A few verbs below are flagged as needing an engine entry or as defective.
- Reflexive and non-reflexive versions are separate entries, as with `levantar` and `levantarse`. Where both are listed, keep them both unless one adds nothing.
- Delete the batch from this file once it's in `verbs.json`, and update the verb count in `plan.md`.
- If a verb is dropped, move it to "Dropped" at the bottom with the reason, so it isn't suggested again.
